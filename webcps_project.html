GPS Roaming (CPS "GPS Roaming"): 32 fixed slots. Each ties a zone to a geographic circle — a centre (latitude/longitude in degrees + minutes, N/S and E/W) and a radius in metres — so the radio switches to that zone inside the circle. Set On/Off off (or the zone to Off) to disable a slot.

The 32 slots are fixed: you edit them, but cannot add or remove one. Changes go into the .rdt file you download, and to the radio when you use Write to Radio.

    How scan lists work

    A scan list is a set of channels the radio steps through, stopping on any that has a signal. Two separate settings decide what it scans:

    Members
    Which lists this channel is scanned in. Tick as many as you like: under Scan Lists in the channel editor, or under Member Channels when you edit a list.
    Start Scan List
    Which list this channel starts when you begin scanning on it. Just one, or None: pick it with the circle beside a list under Scan Lists in the channel editor.

    The two are separate: a channel can start a list it is not in, and being in a list never makes it the start list.

    In the channel editor, CH 3 looks like this:
    Scan List 1
    Scan List 2
    Tick = the lists this channel is scanned in. The circle on the right = the one list it starts when you scan from it (any list).
    Buttons on the Scan Lists tab
    Start on members
    Makes the selected list the start scan list of every channel in it, including members that started another list. Channels outside the list are not changed.
    Clear as start list
    Sets every channel that starts the selected list back to None. They stay members of the list.
    Fill unknown
    For each channel whose start scan list was never read (an older import) or names a deleted list: its first scan list, or None when it is in none. Channels that have a start scan list are not changed.
    Started by
    The column counts the channels that start each list.
